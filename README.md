# Current Divider Circuit Using LM358 Comparator

## Introduction

This project was completed as part of my Electronics course. The main goal was to understand how current is divided in parallel resistor networks and how an LM358 operational amplifier works as a comparator.

The circuit was designed and simulated in **Proteus 8 Professional** and then implemented on a breadboard to verify the results.

## Working

The circuit uses parallel resistors to divide the current into different branches. A potentiometer is used to adjust the reference voltage for the LM358 comparator.

When the voltage at the non-inverting (+) input becomes higher than the inverting (−) input, one LED turns ON. When the input conditions change, the other LED turns ON. This demonstrates the operation of both the current divider and the comparator circuit.
